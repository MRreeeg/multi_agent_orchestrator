## 2026-08-14 执行记录详情：点击卡片查看上次执行的具体情况（L-46）

- 用户反馈：执行记录"毫无用处"，没有记录上一次执行的各个情况；希望点击打开
  显示具体信息，排版干净，从任务总览到各 agent 主要执行情况。
- 落地：
  1. 后端新增 `GET /orchestrator/api/runs/{id}/detail`：返回 run + 其 PipelineRevision
     的节点快照（type/executor/model/name），旧 getRun 保持兼容（前端 showNodeDetail
     不受影响）。
  2. 前端执行详情弹窗（#run-detail-modal）：点击执行记录卡片打开——
     - 总览卡：状态图标/状态/Run id/任务全文/触发/时间范围/节点成功数/总 Token·费用；

     - 各 Agent 卡：类型徽章（架构师/执行者/审查者按语言）、节点名、执行器/模型、

     全部文案接入 i18n（rd.*）；卡片模板加 data-run-id 绑定点击。
  3. 无 revision 节点信息时按 nodeStates 兜底渲染（仅 id + 状态/输出）。
- 验证：Playwright 真实历史 run——弹窗 flex、总览含任务/状态/触发/时间/节点 3/3、
  3 张节点卡、Loop 进度与模式、console 零错误。
- 坑：ServeMux 内部路由分发按 `strings.Count(path,"/")` 精确匹配——`/runs/{id}/detail`
  是 3 层路径，不能放进 count==2 的分支（先 404 过一次）。

## 2026-08-14 英文补漏：执行记录模板串字面量 bug + 画布/工具栏/下拉英文化（L-44）

- 用户反馈：①执行记录卡片显示 `' + T('run.nodes') + '5/5` 这类字面量；②英文
  模式遗漏：加载预设、画布节点类型、端口 badge「进入」、自检「关闭」、管道
  工具栏（自动布局/删除/清空）仍是中文；Windows 系统菜单/标题栏无法改。
- 根因（①）：上一轮 i18n 批量替换把 **backtick 模板字符串**里的拼接写成了单引号
  `' + T(...) + '`——在模板串里单引号是字面字符，渲染出乱字面量。修复：改回
  `${T(...)}` 插值（resume/stop/节点/失败/触发/Loop/模式/终止/Review/第 N 次执行）。
- 落地（②）：badge「进入」→ T('badge.enter')（英文 Enter）；预设下拉静态 option
  与 4919 动态重建 → T('preset.load')；`typeLabels` 4 处与 `createNode` typeNames
  → T；cfg-type 三个 option（含颜色说明）→ T；管道工具栏自动布局/删除/清空
  （按钮文本 + title）→ T；自检「关闭」→ T('dlg.close')；add-node 三个按钮文本
  包 `.pipe-add-label` span 由 applyLang 统一更新（保留 dot 装饰 span）。
- 验证：Playwright 英文模式——runs 卡片 "Run #1 … Nodes: 2/2 Trigger: manual"、
  badge Enter、Load preset...、Auto layout/Delete/Clear、Close、Architect (blue)…、
  + Architect…、画布节点类型 Executor；console 零错误；go build 通过。
- 防回归：i18n 批量替换时**必须区分 backtick 模板串与单引号拼接**；动态重建
  的 HTML（如 4919 预设下拉）也要用 T。

## 2026-08-12 opencode serve 卡死/超时系列修复 + 浏览器窗口 + 控制台渲染

**背景**：架构师/执行者节点（opencode serve + deepseek-v4-flash-free）多次卡死：
模型陷入"探索循环"（反复 read/glob/grep 数预算、复述计划），一次 turn 拖到
HTTP 客户端 10 分钟超时才报错，整条流水线干等。

**改动（serve 模式加固）**

- `internal/executor/opencode/client.go`：
  - `Prompt` 支持 `system` 槽位（serve API 合法字段，比用户消息权威）；
  - `tools` 传参改为 `map[string]bool`（serve API 类型是 Record<toolID,boolean>
    转 permission 规则；`{"*": false}` 全禁，具名 deny 列表做只读模式；
    注意：传 `[]` 数组会 400 `Expected object | null`）；
  - `HistoryMessage` 增加 `CreatedMs`（info.time.created，毫秒），供恢复扫描锚定当前轮；

- `internal/orchestrator/opencode_runtime.go`：
  - `opencodeDiscipline`：turn 预算（默认 5 分钟）+ 三段 system 纪律提示
    （默认 / 只读 / 无工具，最后一种已删——生产无调用者，属死代码）；
  - 预算到期：abort turn → `History` 捞**本轮**（按 turnStart 时间锚定）产出的
    assistant 文本当部分结果交付，零输出才算失败；
    只对 `context.DeadlineExceeded` 恢复，500/连接错误直接失败不捞历史；
  - 只读模式 deny 列表：bash/edit/write/move/patch/create/delete/task/
    webfetch/websearch/mcp__*；保留 read/grep/glob。
- `internal/orchestrator/pipeline.go`：按角色设 serve turn 预算
  （架构师 5 分钟 + ToolsReadOnly，审查者 5 分钟，执行者 15 分钟），
  三个 ExecutorOpencode 判断块合并为一个。
- `internal/executor/opencode/opencode.go`：run 模式透传 `--max-steps`。

**改动（UI）**

- 点 runtime 端口徽章 / Open 按钮 → 新增 `POST /orchestrator/api/runtime/open`
  （校验 loopback http(s)）→ 服务端 `rundll32/open/xdg-open` 打开系统默认浏览器

  展开状态随轮询刷新保留）；回答/推理内容改走主聊天同一个 `renderMarkdown`
  （标题/表格/代码块/加粗/引用），不再裸显示 Markdown 源码。

  `/runs/*/analysis` 260s、`/runtimes/*/message` 300s（后端分别 4 分钟 / 10 分钟），
  修掉"分析失败: 请求超时（15秒）"类误报（前端 15s abort 会把后端子进程/响应掐断）。
- 节点配置卡片的"职责描述"改为只读预览 + 点击弹出大窗口

**实测验证**

- `tools={"*": false}` 与具名 deny 列表用真实 serve + deepseek-v4-flash-free 验证：
